How it Works — Admin Guide

👤
Step 1 — Create a Landlord Account
Go to Manage Landlords in the sidebar. Enter the landlord's full name, email address, and a temporary password. Click Create Account. They'll receive the credentials from you — they can log in immediately and change their password later.
💡 You can create as many landlords as you need. Each one only ever sees their own properties.
🏠
Step 2 — Add a Property
Click Add Property (top-right or sidebar). Fill in the address, type, monthly rent, and status. If occupied, add the tenant's name, contact, and lease dates. At the bottom, use the Assign to Landlord dropdown to link the property to the correct landlord.
💡 A property must be assigned to a landlord — this controls what each landlord sees when they log in.
🔑
Step 3 — Share Access with the Landlord
Send the landlord the site URL and the credentials you set for them. When they sign in, they'll see a dashboard showing only their assigned properties — no other landlord's data is visible to them. They cannot add, edit, or delete anything.
💡 If a landlord forgets their password, go to Firebase Console → Authentication → Users → Reset password.
✏️
Editing & Deleting Properties
As admin you see an edit (pencil) and delete (bin) button on every property row. Use edit to update tenant details, change status between Occupied / Vacant / Maintenance, or reassign a property to a different landlord.
💡 Deleting a property is permanent and cannot be undone.
📊
Filters, Search & Stats
Use the sidebar filters (All / Occupied / Vacant / Expiring Soon) and the type chips (Flat, House, HMO…) to slice the portfolio. The search bar filters by address, tenant name, or landlord name in real time. The four stat cards at the top always reflect the current filtered view.
💡 "Expiring Soon" flags any lease ending within the next 30 days — useful for proactive renewals.
